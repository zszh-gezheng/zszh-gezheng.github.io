Research

My current research focuses on hallucination and reasoning in large vision-language models. In this line of work, I investigate failure modes that emerge in long-form generation, different task formats, and compositional reasoning, and develop diagnostic and mitigation methods for more reliable multimodal behavior. My broader work includes multimodal chain-of-thought reasoning, visual grounding, and visual content generation. Selected papers are highlighted below.

* Equal contribution. † Corresponding author.

Discovering Compositional Hallucinations in LVLMs
Sibei Yang†, Ge Zheng, Jiajin Tang, Jiaye Qian, Hanzhuo Huang, Cheng Shi
NeurIPS, 2025
Paper

LVLMs may answer visual- and textual-centric questions correctly, yet hallucinate when the two are composed into a simple query; this work defines the failure mode as Simple Compositional Hallucination (SCHall), introduces SCBench for diagnosis, and proposes VLR-distillation for mitigation.

Intervene-All-Paths: Unified Mitigation of LVLM Hallucinations across Alignment Formats
Jiaye Qian*, Ge Zheng*, Yuchen Zhu, Sibei Yang†
NeurIPS, 2025
Paper / Code

LVLM hallucinations can arise from different pathways across discriminative and generative alignment formats; AllPath provides a comprehensive view of these pathways and tailors training-free interventions to each format.

Why LVLMs Are More Prone to Hallucinations in Longer Responses: The Role of Context
Ge Zheng*, Jiaye Qian*, Jiajin Tang, Sibei Yang†
ICCV, 2025
Paper / Code

Hallucinated objects tend to appear later within long LVLM responses; this work goes beyond error accumulation to explain long-response hallucinations through contextual coherence and completeness, and explores context-guided object-level detection and mitigation.

MVTokenFlow: High-quality 4D Content Generation using Multiview Token Flow
Hanzhuo Huang*, Yuan Liu*, Ge Zheng, Jiepeng Wang, Zhiyang Dou, Sibei Yang†
ICLR, 2025
Paper / Project Page / Code

MVTokenFlow addresses 4D content generation from monocular videos with a two-stage framework: it first builds coarse structure from reliable front-view optical flows, then refines consistency across viewpoints and timesteps using all-view token flows in the multiview diffusion latent space.

WildRefer: 3D Object Localization in Large-scale Dynamic Scenes with Multi-modal Visual Data and Natural Language
Zhenxiang Lin, Xidong Peng, Peishan Cong, Ge Zheng, Yujing Sun, Yuenan Hou, Xinge Zhu, Sibei Yang, Yuexin Ma†
ECCV, 2024
Paper / Code

WildRefer studies 3D visual grounding in large-scale dynamic scenes, introducing human-centric multimodal datasets and a multimodal grounding approach that explores temporal information and multi-modal feature fusion for target localization.

DDCoT: Duty-Distinct Chain-of-Thought Prompting for Multimodal Reasoning in Language Models
Ge Zheng*, Bin Yang*, Jiajin Tang*, Hong-Yu Zhou, Sibei Yang†
NeurIPS, 2023
Paper / Project Page / Code

DDCoT distinguishes visual-evidence needs from language-side reasoning, enabling LLMs to critically integrate external visual information and generate explainable multimodal rationales in a zero-shot manner.

CoTDet: Affordance Knowledge Prompting for Task Driven Object Detection
Jiajin Tang*, Ge Zheng*, Jingyi Yu, Sibei Yang†
ICCV, 2023
Paper / Project Page / Code

Task-driven object detection requires models to identify objects that can accomplish abstract tasks; CoTDet leverages LLM reasoning over object candidates and functional cues to derive visual attributes as visual affordance knowledge, which guides detection and localization.

Temporal Collection and Distribution for Referring Video Object Segmentation
Jiajin Tang, Ge Zheng, Sibei Yang†
ICCV, 2023
Paper / Project Page

Referring video object segmentation requires modeling cross-frame dynamics in language expressions while producing frame-level masks; TempCD bridges this mismatch through temporal collection and distribution between a global referent token and frame-level object queries.

Contrastive Grouping with Transformer for Referring Image Segmentation
Jiajin Tang, Ge Zheng, Cheng Shi, Sibei Yang†
CVPR, 2023
Paper / Code

CGFormer enhances referring image segmentation with a mask-classification framework that models object-level queries through token grouping and contrastive learning, with a consecutive decoder enabling cross-level interaction between queries and masks.
