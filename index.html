I am a recent M.S. graduate in Computer Science and Technology from ShanghaiTech University, where I also received my B.S. My research focuses on making large multimodal models more reliable, particularly by understanding and mitigating hallucinations. My broader interests include multimodal reasoning, visual grounding, and evaluation. I am currently seeking research opportunities in multimodal AI across academia and industry.

My work has been published in NeurIPS, ICCV, ICLR, CVPR, and ECCV, including four papers as first or co-first author.

Research

My current research mainly studies hallucination and reasoning in large vision-language models. In this line of work, I examine failure patterns in long-form generation, different alignment formats, and compositional reasoning. I have also explored related problems in multimodal chain-of-thought reasoning and object detection with visual affordance knowledge. Selected papers are highlighted below.

* Equal contribution. † Corresponding author.

Discovering Compositional Hallucinations in LVLMs
Sibei Yang†, Ge Zheng, Jiajin Tang, Jiaye Qian, Hanzhuo Huang, Cheng Shi
NeurIPS, 2025
Paper

We identify simple compositional hallucination (SCHall), introduce the SCBench diagnostic benchmark, and propose VLR-distillation to mitigate this failure mode.

Intervene-All-Paths: Unified Mitigation of LVLM Hallucinations across Alignment Formats
Jiaye Qian*, Ge Zheng*, Yuchen Zhu, Sibei Yang†
NeurIPS, 2025
Paper / Code

We uncover distinct hallucination pathways across discriminative and generative alignment formats and introduce AllPath, a training-free intervention framework targeting critical attention heads.

Why LVLMs Are More Prone to Hallucinations in Longer Responses: The Role of Context
Ge Zheng*, Jiaye Qian*, Jiajin Tang, Sibei Yang†
ICCV, 2025
Paper / Code

We show that hallucinations in longer responses arise from increased reliance on context and introduce an induce-detect-suppress framework for object-level detection and mitigation.

MVTokenFlow: High-quality 4D Content Generation using Multiview Token Flow
Hanzhuo Huang*, Yuan Liu*, Ge Zheng, Jiepeng Wang, Zhiyang Dou, Sibei Yang†
ICLR, 2025
Paper / Project Page / Code

We generate high-quality 4D content from monocular videos by combining multiview diffusion with rendered 2D token-flow guidance for spatial and temporal consistency.

WildRefer: 3D Object Localization in Large-scale Dynamic Scenes with Multi-modal Visual Data and Natural Language
Zhenxiang Lin, Xidong Peng, Peishan Cong, Ge Zheng, Yujing Sun, Yuenan Hou, Xinge Zhu, Sibei Yang, Yuexin Ma†
ECCV, 2024
Paper / Code

We introduce 3D visual grounding in large-scale dynamic scenes, two human-centric datasets, and a multimodal method that integrates image appearance, point-cloud geometry, and language.

DDCoT: Duty-Distinct Chain-of-Thought Prompting for Multimodal Reasoning in Language Models
Ge Zheng*, Bin Yang*, Jiajin Tang*, Hong-Yu Zhou, Sibei Yang†
NeurIPS, 2023
Paper / Project Page / Code

We introduce duty-distinct chain-of-thought prompting, combining critical thinking with explicit responsibility separation to generate generalizable and explainable multimodal rationales.

CoTDet: Affordance Knowledge Prompting for Task Driven Object Detection
Jiajin Tang*, Ge Zheng*, Jingyi Yu, Sibei Yang†
ICCV, 2023
Paper / Project Page / Code

We introduce multi-level chain-of-thought prompting to extract visual affordance knowledge from LLMs and use it to guide task-driven object detection and segmentation.

Temporal Collection and Distribution for Referring Video Object Segmentation
Jiajin Tang, Ge Zheng, Sibei Yang†
ICCV, 2023
Paper / Project Page

We introduce a temporal collection-distribution mechanism that connects video-level language grounding with frame-level object segmentation for consistent referring video object segmentation.

Contrastive Grouping with Transformer for Referring Image Segmentation
Jiajin Tang, Ge Zheng, Cheng Shi, Sibei Yang†
CVPR, 2023
Paper / Code

We introduce CGFormer, a query-based mask-classification framework that combines contrastive learning with object-level grouping for referring image segmentation.
